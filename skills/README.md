# スキルの保管場所

Claude Code のセッションで作ったスキルのバックアップです。
セッションのコンテナは一定時間で破棄されるため、ここに置いて残しています。

## lp-build-and-preview

LP制作 → パスワード付きの確認用URLを GitHub Pages で発行 → 
あとから GitHub のLPを呼び出して修正、までを一貫して扱うスキル。

- `lp-build-and-preview/` … スキル本体（このまま読める）
- `lp-build-and-preview.skill` … 配布用のパッケージ（中身は上と同じZIP）

### 使えるようにする方法

**方法1：ファイルカードから登録する（かんたん）**

Claude に `.skill` ファイルを送ってもらうと、会話にファイルカードが出ます。
そこに **Save skill** ボタンがあれば、押すだけでアカウントに登録され、
以降のセッションで自動的に使えるようになります。

**方法2：セッションに読み込ませる**

ボタンが出ない場合は、新しいセッションで Claude にこう頼んでください。

> このリポジトリの skills/lp-build-and-preview/ を読んで、その手順でやって

`SKILL.md` を読ませれば、登録しなくても中身の手順どおりに動きます。
