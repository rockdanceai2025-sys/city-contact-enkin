# フォントとロゴのライセンス事故を防ぐ

制作物は商用の広告なので、フォントのライセンス違反は直接の金銭リスクになる。
**Monotype 社は買収で多数のブランドを傘下に収めており、Webサイトを巡回して
使用状況を調べ、高額なライセンス料を請求することで知られている。**
「知らずに使っていた」は通用しないので、**そもそも使わない状態を保つ**のが唯一の対処になる。

隠す・逃れるという発想は取らない。配信物から完全に排除すれば、見つかるものが存在しない。

---

## 3つの原則

### 原則1：ロゴはラスターデータを流用する

**ロゴは JPEG / PNG の画像をそのまま使う。** フォントで組み直さない。

理由は2つある。

- ロゴに使われている書体は、たいてい商用フォントか、その加工物。
  同じ見た目を出そうとしてフォントを指定すると、そのフォントのライセンスが要る。
- 文字をアウトライン化してSVGに埋め込むのも**フォントの派生物**にあたるため、
  「アウトライン化すれば安全」は誤り。

クライアントからロゴをもらうときは、**画像データ（JPEG/PNG/aiのラスター書き出し）**で受け取る。
SVGで渡されたら、中身に `font-family` や埋め込みフォントが無いか必ず開いて確認する。

ロゴ画像が無く、こちらで作る必要があるときは、**文字を使わない図形だけのマーク**にするか、
SIL OFL のフォント（Noto 等）で組む。どちらにするかは必ず確認を取る。

### 原則2：Webフォントは SIL Open Font License のものだけ

```css
:root {
  --font: "Noto Sans JP", sans-serif;
  --font-serif: "Noto Serif JP", serif;
}
```

**名指ししてよいのは、ライセンスが明確に無償・商用可のものだけ。**

| 使ってよい | 理由 |
| --- | --- |
| Noto Sans JP / Noto Serif JP | SIL OFL 1.1。商用利用・改変・再配布が無償 |
| M PLUS 1p / 2p、Zen 各種、Klee One（Google Fonts版） | 同上 |
| IBM Plex Sans JP | SIL OFL 1.1 |
| BIZ UDPGothic / BIZ UDPMincho | SIL OFL 1.1（モリサワが公開） |
| Adobe Fonts の書体 | Creative Cloud 契約の範囲内なら可。契約が切れると使えなくなる点に注意 |

**フォールバックには総称（`sans-serif` / `serif`）だけを置く。**
`"Hiragino Sans"` `"Yu Gothic"` `"Meiryo"` のようにOSのフォント名を並べるのはよくある書き方で、
閲覧者の端末にあるフォントが使われるだけなのでライセンス違反にはならない。
ただしデベロッパーツールに商用フォント名が並ぶと、クライアントに説明する手間が生じる。
**名指ししないほうが後が楽。**

### 原則3：Monotype 系は名前すら出さない

Monotype が所有・管理するブランドは広い。代表的なものは次のとおり。
**早見表は `references/monotype-brands.md`。ただしこれは完全なリストではない。**
表に無い書体は都度調べること（同ファイルの「調べ方」に手順がある）。
表の最終確認日から半年以上経っていたら、買収情報を確認して更新する。

- **Monotype 本体**：Arial、Times New Roman、Gill Sans、Rockwell、Baskerville、Perpetua
- **Linotype 由来**（2006年に買収）：Helvetica、Univers、Frutiger、Optima、Palatino、**Avenir**
- **ITC 由来**：Avant Garde、Franklin Gothic、Lubalin、Officina
- **フォントワークス**（2021年に買収）：**筑紫書体**、ロダン、マティス、スーラ、セザンヌ、丸フォーク

特に危険なのは、**意識せず使ってしまう経路**にあるもの。

- **Avenir** は macOS / iOS に標準搭載されている。CSSでよく使われる
- **筑紫A丸ゴシック / 筑紫B丸ゴシック** は macOS に標準搭載、**かつ Canva にも入っている**

## 3つの落とし穴

### 落とし穴1：ブラウザの標準指定

CSSで何も指定しないと、**`html` 要素は Times New Roman、フォーム部品は Arial** になる。
どちらも Monotype。自分では一文字も書いていないのに、デベロッパーツールには出る。

```css
html { font-family: var(--font); }
input, select, textarea, button { font-family: inherit; }
```

この2行を必ず入れる。`body` に指定するだけでは `html` が残る。

### 落とし穴2：SVG の中の font-family

装飾的なラベル（BEFORE / AFTER、バッジ、OGP画像の文字）に、
うっかり `font-family="Helvetica, Arial, sans-serif"` と書いてしまいやすい。
**SVG内の指定もCSSと同じものに揃える。**

OGP画像をSVGで作る場合、`<text>` は残したまま（アウトライン化しない）、
font-family を OFL のものにする。

### 落とし穴3：デザインツールからの持ち込み

**Canva には筑紫A丸ゴシック・筑紫B丸ゴシックが入っている。**
Canva の中で使う分には同社の規約の範囲だが、**制作物側に持ち込むのは別問題**。

| 持ち込み方 | 可否 | 理由 |
| --- | --- | --- |
| PNG / JPG で書き出す | ○ | 文字が画像に焼き込まれ、フォントの情報は残らない |
| SVG / PDF で書き出す | ✖ | フォント名やアウトラインが配信物に残る |
| フォントファイルを取り出して webfont にする | ✖ | 明確なライセンス違反 |

**デザインツールの素材は必ずラスター画像で受け取る。**
Illustrator・Figma・Photoshop も同じ。

書き出した画像の**メタデータに制作ツール名やフォント名が残る**ことがある。
後述の監査スクリプトがそこまで検査する。

## 検出クローラーについて

フォントベンダーは、ライセンス確認のためにWebサイトを巡回している。
読み取られるのは、**こちらが配信しているファイルの中身**。

| 読み取れる | 読み取れない |
| --- | --- |
| CSSの `font-family` | ラスター画像に焼き込まれた文字の書体 |
| `@font-face` と配信しているフォントファイル | |
| SVG内の `font-family`、埋め込みフォント | |
| 画像のメタデータ（EXIF / XMP） | |

だから**ロゴをJPEGで流用する**のが安全であり、
**使わない状態にしておけば見つかるものが無い**という結論になる。

検出を逃れる小細工（難読化、クローラー除外など）は取らない。
実際に使っていれば、それは隠しているだけで違反は成立している。

## 納品前チェック（必須）

目視では必ず取りこぼす。機械的に検査する。

```bash
node scripts/audit-fonts.js --browser
```

検査する内容：

1. `font-family` の**値**に Monotype 系の名前がないか
   （本文中の「筑紫野市」のような地名は誤検知しない）
2. フォントファイル（.woff / .ttf / .otf 等）を同梱していないか
3. `@font-face` と、外部フォントの取得先
4. 画像のメタデータに「Canva」「筑紫」等の痕跡が残っていないか
5. `--browser` を付けると、ブラウザの計算値も検査
   （ブラウザ標準の Times New Roman / Arial を捕捉できる）

**危険なものが見つかると終了コード1で落ちる。** 制作物の `tools/` にコピーして使う。

手で確認するときは、デベロッパーツール → Elements → **Computed** タブの一番下の
**Rendered Fonts**。ここに実際に描画されたフォント名が出る。

## 新しいフォントを足したいと言われたとき

クライアントや制作側から「この書体を使いたい」と言われたら、**その場で決めない。**

1. `references/monotype-brands.md` で Monotype 系かどうか照合する。
   **照合表は完全なリストではない。** 買収は随時起きるので、
   **表に無い書体は「安全」ではなく「未確認」**として扱い、
   同ファイルの「調べ方」に従って WebSearch で権利者を確認する
2. Monotype 系なら、**使えない理由を具体的に説明し、代替案を出す**
   （例：筑紫A丸ゴシック → Zen Maru Gothic、M PLUS Rounded 1c）
3. Monotype 系でなくても、**Webフォントとして配信するならライセンス購入が必要**。
   誰が費用を負担するかを確認する
4. 判断がつかなければ、**Google Fonts の中から近い書体を提案する**

**フォントは着手時点で決めておく。** あとから差し替えると、
字幅が変わって行数がずれ、レイアウトを組み直すことになる。
