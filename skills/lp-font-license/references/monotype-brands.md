## 特に危険な経路

意識せず使ってしまうもの。**ここが事故の起点になりやすい。**

| 書体 | どこに入っているか |
| --- | --- |
| **Avenir / Avenir Next** | macOS・iOS に標準搭載。CSSでよく書かれる |
| **筑紫A丸ゴシック / 筑紫B丸ゴシック** | macOS に標準搭載、**かつ Canva にも収録** |
| **Helvetica** | macOS に標準搭載。「とりあえず」で書かれがち |
| **Arial / Times New Roman** | Windows に標準搭載。**ブラウザの標準指定でも使われる** |

OSに入っている＝自由に使ってよい、ではない。
端末で表示するだけなら問題ないが、**Webフォントとして配信したり、
文字をアウトライン化して配布物に埋め込んだりすると違反になる。**

## 判断に迷ったら

- 書体名で検索して権利者を確認する
- 権利者が分からない書体は**使わない**
- クライアント支給のロゴは、**フォントで組み直さずラスター画像を流用する**
- 最終的なライセンス判断は法務の領域。グレーなら顧問に確認してもらう

## 調べ方（表に無い書体が出てきたとき）

**表を全部維持しようとしない。** 買収は随時起きるので、リストは必ず古くなる。
実務では「いま話題に出ているその書体」を調べるほうが確実で速い。

### 1. 権利者を調べる

WebSearch で次のように検索する。

```
"<書体名>" フォント 権利者 販売元
"<書体名>" font foundry publisher
"<書体名>" Monotype
```

判定の目安：

| 検索結果に出てくるもの | 判定 |
| --- | --- |
| monotype.com / fonts.com / MyFonts / Linotype / ITC | **Monotype 系。使わない** |
| フォントワークス / Fontworks | **Monotype 系（2021年に買収）。使わない** |
| Google Fonts / SIL Open Font License | 使ってよい |
| モリサワ / 字游工房 / SCREEN / ダイナフォント / イワタ | Monotype ではない。ただし有償なので契約の確認が要る |
| 権利者がはっきりしない | **使わない。** 分からないものは避ける |

### 2. 買収されていないか確認する

有名な書体ほど、権利が移っていることがある。

```
"<書体名>" 買収 権利 移管
"<foundry名>" acquired by Monotype
```

### 3. 結果を表に書き足す

調べた結果は、この表の該当セクションに追記して、最終確認日を更新する。
次に同じ書体が出たときに調べ直さずに済む。

## 更新のしかた（半年ごと、または大きな買収の報道があったとき）

Claude に次のように頼む。

```
lp-font-license スキルの references/monotype-brands.md を更新してください。
最終確認日以降に Monotype 社が買収したフォントベンダーや、
権利が移管された書体がないか調べて、あれば表に追記してください。
併せて scripts/audit-fonts.js の判定リストにも反映してください。
```

調べるべき情報源：

- Monotype の企業ニュース（買収の発表）
- 「Monotype 買収 フォント」「Monotype acquires foundry」での検索
- 日本語の書体は「フォントワークス」以外にも買収がないか確認する

**買収は年に1回あるかないかの頻度なので、半年ごとの確認で足りる。**
表を毎日更新する必要はない。危険なのは「何年も見直していない」状態。

### 自動で通知を受け取りたい場合

Claude の Routine（定期実行）を設定すれば、定期的に買収情報を調べて
報告させることができる。設定を頼むときは次のように言う。

```
半年に1回、Monotype社のフォントベンダー買収情報を調べて、
lp-font-license スキルの照合表に追記が必要か報告する Routine を作ってください。
```
