### フォームの送信先が未設定です

`index.html` のフォームは `action="#"` のままです。
ご利用のフォームシステム（CMS・メールフォームサービス等）に合わせて `action` / `method` を設定してください。

```html
<form class="p-form" id="js-form" action="#" method="post" novalidate>
```

送信先が未設定のあいだは、送信ボタンを押すと「まだ送信先が設定されていません」という案内を表示します。
`action` を設定すると、この案内は自動的に出なくなり、通常のフォーム送信に切り替わります（`assets/js/main.js`）。

### noindex を削除してください

確認用サイトを検索結果に出さないため、`index.html` の冒頭に次の1行が入っています。

```html
<meta name="robots" content="noindex, nofollow">
```

**本番サーバーへ設置する際は、この1行を必ず削除してください。**
残したまま公開すると、本番ページが検索結果に表示されなくなります。

### OGP画像・canonical

- `og:image` はSVG（`assets/img/ogp.svg`）です。SNSシェアの互換性を考える場合は **1200×630のPNGに書き出して** 差し替えてください。
- `og:image` / `og:url` / `<link rel="canonical">` は相対パスまたは未設定です。公開URLが決まったら絶対URLを設定してください。

## 原稿に関する注意（重要）

掲載している数値・事例・お客様の声は、**いただいた企画提案書の記載をそのまま反映したもの**です。
実際の実績と異なる場合は、掲載前に必ず差し替えてください。

- **料金表**（1K 38,000円〜／4LDK・5DK 250,000円〜）… 提案書の「自社プラン（作業員手厚め設定）」に準拠
- **事例①** 福岡県久留米市・戸建て4LDK／作業員5名・1.5日／320,000円 − 買取相殺35,000円 = 285,000円
- **事例②** 提案書では「佐賀県鳥栖市」でしたが、**福岡県全域への訂正にともない「福岡県北九州市」に変更**しています
- **お客様の声** … 提案書の記載どおり。1件目の出身地を「佐賀出身」から「福岡県ご出身」に変更しています
- 「追加料金一切なし」「最短即日」などは**実際の運用と一致しているか**をご確認ください（景品表示法上、実現できない表示は不当表示になります）
- 遺品の買取を行う場合、**古物商許可の表示が必要**です。フッターに記載欄を設けていますので、実際の許可番号を入れてください

## 配色（トンマナ）

構成案のご指定「落ち着いた紺・温かみのあるアースカラー」に沿っています。
`assets/css/style.css` の `:root` にすべて集約しているため、数値の差し替えだけで全体に反映されます。

| 変数 | 値 | 用途 |
| --- | --- | --- |
| `--c-navy` | `#23415f` | メインの紺（見出し・フォーム・CVエリア背景） |
| `--c-navy-dark` | `#17304a` | 濃い紺（グラデーション・ホバー） |
| `--c-navy-pale` | `#eef3f8` | 淡い紺背景（お悩みセクション） |
| `--c-earth` | `#b87a44` | アースカラー（CTAボタン・アイコン） |
| `--c-earth-dark` | `#9a6234` | 濃いアースカラー（金額・強調） |
| `--c-earth-pale` | `#fbf1e4` | 淡いベージュ背景 |
| `--c-cream` | `#fbf8f3` | クリーム背景（セクション交互） |

フォントは見出しに `Noto Serif JP`、本文に `Noto Sans JP`（Google Fonts）を使用しています。
どちらも読み込めない環境ではヒラギノ・游ゴシック等にフォールバックします。

## シニア視認性への対応（構成案のご指定）

- 本文の基準フォントサイズを **17px**（スマホ16.5px）に設定
