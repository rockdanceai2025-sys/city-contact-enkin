### 申し込みフォームの動き

送信先は **tsumugi@tsumugi-lp.net** です。動作は2段階になっています。

1. `action` が設定されていれば、そのフォームシステムへ通常どおり送信する
2. 未設定のあいだは、`data-mailto` のアドレス宛に**メールを作成する**
   （入力内容を件名・本文に差し込んだ状態で、閲覧者のメールソフトが開く）

```html
<form class="p-form" id="js-form" action="#" method="post" novalidate
      data-mailto="tsumugi@tsumugi-lp.net">
```

いまは 2 の状態なので、**サーバー側の仕組みが無くてもフォームは使えます。**
送信されるメールはこの形式です。

```
件名：【無料お見積もりのご依頼】福岡 太郎

片づけ処 つむぎ 御中

ホームページのフォームよりお見積もりを依頼します。

────────────────
お名前：福岡 太郎
電話番号：090-1234-5678
メールアドレス：taro@example.com
物件の所在地：福岡県久留米市国分町
間取り：3DK・3LDK
立ち会いの有無：立ち会いなし
ご相談内容：来月中に作業をお願いしたいです。
────────────────
```

メールソフトが開かない環境のために、画面にもアドレスと電話番号を案内しています。

**本番でフォームシステム（CMS・メールフォームサービス等）に接続する場合**は、
`action` に送信先を設定してください。それだけで 1 に切り替わり、メール作成は行われなくなります。
`data-mailto` は残しておいて構いません（`action` が優先されます）。

※ メールソフトを使っていない閲覧者（Webメールのみの方）は送信できないため、
取りこぼしを避けたい場合は、フォームシステムへの接続をおすすめします。

### noindex を削除してください

確認用サイトを検索結果に出さないため、`index.html` の冒頭に次の1行が入っています。

```html
<meta name="robots" content="noindex, nofollow">
```

**本番サーバーへ設置する際は、この1行を必ず削除してください。**
残したまま公開すると、本番ページが検索結果に表示されなくなります。

### OGP画像・canonical

- `og:image` はSVG（`assets/img/ogp.svg`）です。SNSシェアの互換性を考える場合は **1200×630のPNGに書き出して** 差し替えてください。
- `og:image` / `og:url` / `<link rel="canonical">` は相対パスまたは未設定です。公開URLが決まったら絶対URLを設定してください。

## 原稿に関する注意（重要）

料金表とサービス内容は**既存サイトの掲載内容**に、事例・お客様の声は**企画提案書の記載**にもとづいています。
実際の実績と異なる場合は、掲載前に必ず差し替えてください。

- **料金表**（1R・1K 25,000円〜／4LDK以上・一戸建て 200,000円〜）… **既存サイト（片づけ処 つむぎ）の掲載内容に準拠**。企画提案書の数値とは異なります
- **事例①** 福岡県久留米市・戸建て4LDK／作業員5名・1.5日／320,000円 − 買取相殺35,000円 = 285,000円
- **事例②** 提案書では「佐賀県鳥栖市」でしたが、**福岡県全域への訂正にともない「福岡県北九州市」に変更**しています
- **お客様の声** … 提案書の記載どおり。1件目の出身地を「佐賀出身」から「福岡県ご出身」に変更しています
- 「追加料金一切なし」「最短即日」などは**実際の運用と一致しているか**をご確認ください（景品表示法上、実現できない表示は不当表示になります）
- 遺品の買取を行う場合、**古物商許可の表示が必要**です。フッターに記載欄を設けていますので、実際の許可番号を入れてください

## フォントのライセンス

**配信しているフォントは Noto Sans JP / Noto Serif JP のみ**です（Google Fonts 経由）。
どちらも SIL Open Font License 1.1 で、商用利用・改変・再配布が無償で認められています。

CSS・SVG のいずれにも、**Monotype 社のフォント（Helvetica・Arial・Times New Roman 等）は
一切指定していません。** ブラウザの標準指定（`html` は Times New Roman、フォーム部品は Arial）も
明示的に上書きしてあります。

| 対象 | 指定しているフォント |
| --- | --- |
| 本文 | `"Noto Sans JP", sans-serif` |
| 見出し | `"Noto Serif JP", serif` |
| SVG内のテキスト（OGP・事例図） | 同上 |
| ロゴ | フォントを使わない図形のみ（文字のアウトライン化なし） |

フォールバックは `sans-serif` / `serif` の総称のみにしてあります。
Google Fonts が読めない環境では OS 標準のフォントで表示されますが、
これは閲覧者の端末にあるフォントが使われるだけで、配信も複製もしていません。

### 確認のしかた（デベロッパーツール）

1. ページを開いて F12 → **Elements**
2. 要素を選び、右側の **Computed** タブを一番下までスクロール
3. **Rendered Fonts** に、実際に描画に使われたフォント名が出る

`font-family` の指定値は Computed の `font-family` で確認できます。

### 納品前のチェック

```bash
node tools/audit-fonts.js --browser
```

危険なフォント名・同梱フォント・画像メタデータの痕跡を検査し、
見つかれば終了コード1で落ちます。**公開前に必ず通してください。**

### Canva などから素材を持ち込むとき

**Canva には筑紫A丸ゴシック・筑紫B丸ゴシックが入っています**（フォントワークス製、
同社は2021年に Monotype 傘下）。Canva内で使う分には同社の規約の範囲ですが、
LP側に持ち込むときは**必ず PNG / JPG で書き出してください。**
SVG や PDF で書き出すと、フォント名やアウトラインが配信物に残ります。

### 今後フォントを足すとき

- **Monotype 系**：Helvetica、Arial、Times New Roman、Gill Sans、Futura ほか。
  日本語では **フォントワークス（筑紫書体・ロダン・マティス等）が2021年に Monotype 傘下**に入っています。
- 迷ったら、Google Fonts（SIL OFL）か、Adobe Fonts（Creative Cloud 契約の範囲内）に限定するのが安全です。
