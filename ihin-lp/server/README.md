# エックスサーバーへの設置手順

独自ドメイン `tsumugi-lp.net` でLPを公開し、申し込みフォームを動かすまでの手順です。
サーバーパネルの画面は変わることがあるので、**項目名が少し違っても落ち着いて近いものを探してください。**

## 用意するもの

`dist-xserver/` の中身一式（`python3 tools/build-xserver.py` で作られます）。

```
index.html   … フォームの送信先を form.php に設定済み
assets/      … CSS・JS・画像
form.php     … フォームを受け取ってメールを送るプログラム
```

このフォルダの**中身を**サーバーに置きます（フォルダごとではありません）。

---

## 1. ドメインをサーバーに紐づける

エックスサーバーの **サーバーパネル** にログインします
（契約時のメールにURLとIDが書かれています。会員用の「Xserverアカウント」とは別の画面です）。

1. **ドメイン設定** を開く
2. **ドメイン設定追加** タブを選ぶ
3. `tsumugi-lp.net` を入力
4. **「無料独自SSLを利用する」にチェックを入れたまま**追加する

SSLは `https://` で表示するために必要です。チェックを外すと後から設定する手間が増えます。

反映には時間がかかります。**ドメイン追加は数分〜1時間、SSLは最大1時間ほど**見てください。
この間「無効なURL」と表示されても、設定が間違っているとは限りません。

> すでにメールアカウントを作っているなら、ドメイン自体はサーバーに登録済みのはずです。
> その場合は **ドメイン設定** の一覧に `tsumugi-lp.net` が出ているので、この手順は不要です。

## 2. ファイルを置く

サーバーパネルの **ファイル管理**（ファイルマネージャ）を開きます。
FTPソフトに慣れていれば、そちらでも構いません。

置き場所は次のとおりです。

```
tsumugi-lp.net / public_html /
```

**`public_html` の直下**に、`index.html`・`assets`・`form.php` を置きます。

```
public_html/
├── index.html
├── form.php
└── assets/
    ├── css/style.css
    ├── js/main.js
    └── img/（画像5点）
```

`public_html` の中に最初から入っている `default_page.png` や `index.html`（エックスサーバーの
初期ページ）は、削除するか上書きして構いません。

**よくある失敗**：`public_html/dist-xserver/index.html` のように、フォルダごと置いてしまうと
`https://tsumugi-lp.net/dist-xserver/` でしか表示されません。**中身だけ**を置いてください。

## 3. 表示を確認する

ブラウザで `https://tsumugi-lp.net/` を開きます。

- `http://` ではなく **`https://`** で開けるか
- 画像が表示されているか
- スマホでも崩れていないか

画像が出ない場合は、`assets` フォルダを置き忘れているか、階層がずれています。

## 4. フォームの動作を確認する

**必ず自分で一度送信してテストしてください。** これを飛ばすと、
お客様の問い合わせが届いていないことに後から気づくことになります。

1. フォームに自分の情報を入力して送信する
2. 「お申し込みを承りました」の画面が出るか
3. `tsumugi@tsumugi-lp.net` に **【お見積もり依頼】** のメールが届くか
4. 入力したアドレスに **自動返信** が届くか

### 届かないときの確認

| 症状 | 確認すること |
| --- | --- |
| 画面は出るがメールが来ない | 迷惑メールフォルダ。`form.php` の `$TO` のつづり |
| 「送信できませんでした」と出る | サーバーパネルでメールアカウントが有効か |
| ファイルがそのまま表示される | `form.php` が `public_html` の直下にあるか |
| 404 になる | `form.php` のファイル名（拡張子 `.php`）を確認 |

迷惑メール扱いを減らすには、サーバーパネルの **DNSレコード設定** で
**SPFレコード**が設定されているか確認してください（エックスサーバーでは通常は自動で入っています）。

---

## 設定を変えたいとき

`form.php` の冒頭にまとまっています。ここだけ書き換えてください。

```php
$TO        = 'tsumugi@tsumugi-lp.net';   // 受信するアドレス
$FROM      = 'tsumugi@tsumugi-lp.net';   // 送信元
$SHOP      = '片づけ処 つむぎ';
$TEL       = '0120-373-880';
$HOURS     = '8:00〜20:00（土日祝も対応・年中無休）';
$AUTO_REPLY = true;                       // 自動返信を送るか
```

**`$FROM` は必ず自分のドメインのアドレスにしてください。**
お客様のアドレスを差出人にすると、なりすましと判定されて届かなくなります。
お客様への返信は、受信メールの「返信」で届くようにしてあります（Reply-To を設定済み）。

## 迷惑メール対策について

フォームには、人には見えない入力項目を1つ入れてあります。
自動プログラムはここに入力してしまうため、その送信はメールを送らずに終了します。

これでも迷惑メールが増える場合はご相談ください。reCAPTCHA の導入などで対応できます。
