クリエイティブサンプルの現物は `docs/creative-reference/` に格納しています。

### ⚠️ 表現上の注意（薬機法・景表法）

- **「無料視力チェック」の表現は全て削除しました。** 眼科での検査・診察には診察料がかかるため、「無料」と受け取られる表現はトラブルの原因になります。
- 現在の表現：**「レンズ選びのご相談は無料です」**（＝店舗でのレンズ相談のみが無料）
- 眼科併設セクションとCVセクションに **「眼科での検査・診察には、別途 診察料（保険診療の場合は自己負担分）が必要です」** を明記しています。

## 2. コピーの設計方針

- **「老眼」は見出し・本文コピーに使わない**（企画書の指示）。「手元の見えにくさ」「ピント調節の変化」に統一。
  ※ 検索流入を考慮し、`meta keywords` にのみ残しています。不要であれば削除してください。
- **割引・価格訴求は一切入れていません**。価値の軸は「全店眼科併設の安心」と「パーソナライズ」。
- **「どちらかを選ばなくていい」を通しのメッセージに**。遠く用レンズなら手元がぼやけ、手元用メガネなら遠くがぼやける——その二者択一からの解放として遠近両用を位置づけています。
- カラコンは若年層向けの「盛る」文脈を使わず、「ととのえる」「なじむ」「印象」で統一。
- 医療機器としての注意文と「個人差があります」を各所に配置。

## 3. クリエイティブ（画像素材）

すべてSVGで新規制作。写真素材へ差し替える場合もレイアウトはそのまま使えます。

| ファイル | 内容 | 差し替え時の推奨 |
| --- | --- | --- |
| `kv-photo.jpg` | メインビジュアルの写真（クリエイティブサンプルから抽出） | **要差し替え：解像度が256×326pxしかありません**（提案書内の画像を切り出したため）。元の写真データをご支給ください |
| `kv-main.svg` | （旧）女性の顔を左右分割したイラスト。現在は未使用 | 写真を使わない場合の代替案として保管 |
| `focus-range.svg` | ピントが合う距離の変化（以前／40代から／遠近両用） | そのまま使用可 |
| `mechanism.svg` | 同心円の度数配置図（近く／中間／遠く） | メーカー提供の構造図があれば差し替え可 |
| `clinic.svg` | 併設眼科での診察・処方 → 店舗でのレンズ選びの流れ | 店舗・スタッフの実写に差し替え推奨 |
| `color-lens.svg` | カラーレンズ4色（ブラウン／オリーブ／グレージュ／ブラック） | 実際の取扱製品の画像へ |

※ 目のクローズアップや眼球断面のイラストは使用していません。
※ 生活シーン6枚はサンプル内の写真が1枚あたり約54×100pxしかなく使用できないため、線アイコンで構成しています。写真データをご支給いただければ差し替えます。

## 4. 実装メモ

- ライブラリ不使用のバニラJS（シミュレーターとフェードインのみ）。CMSへの貼り付け時もJS競合が起きにくい構成です。
- 配色は `assets/css/style.css` の `:root` に集約。ブランドカラーの正式値が決まれば1か所の差し替えで全体に反映されます。
- レスポンシブ：900px以下でヘッダーナビを省略、640px以下で画面下に追従CTAを表示。横スクロール発生なしを検証済み。
