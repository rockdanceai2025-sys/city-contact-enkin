## 2. コピーの設計方針

- **「老眼」は見出し・本文コピーに使わない**（企画書の指示）。「手元の見えにくさ」「ピント調節の変化」に統一。
  ※ 検索流入を考慮し、`meta keywords` にのみ残しています。不要であれば削除してください。
- **割引・価格訴求は一切入れていません**。価値の軸は「全店眼科併設の安心」と「パーソナライズ」。
- **「どちらかを選ばなくていい」を通しのメッセージに**。遠く用レンズなら手元がぼやけ、手元用メガネなら遠くがぼやける——その二者択一からの解放として遠近両用を位置づけています。
- カラコンは若年層向けの「盛る」文脈を使わず、「ととのえる」「なじむ」「印象」で統一。
- 医療機器としての注意文と「個人差があります」を各所に配置。

## 4. 実装メモ

- ライブラリ不使用のバニラJS（シミュレーターとフェードインのみ）。CMSへの貼り付け時もJS競合が起きにくい構成です。
- 配色は `assets/css/style.css` の `:root` に集約。ブランドカラーの正式値が決まれば1か所の差し替えで全体に反映されます。
- レスポンシブ：900px以下でヘッダーナビを省略、640px以下で画面下に追従CTAを表示。横スクロール発生なしを検証済み。
