## 2. コピーの設計方針

- **主役は「見え方」ではなく「気づかれないこと」**。機能訴求（度数・デザイン）は仕組みセクションに集約し、
  それ以外は生活シーン（会議、メニュー、ゴルフ、値札）で語る。
- 「老眼」という言葉は避けきらず、**正しく・やさしく**説明する。隠すとかえって不信につながるため、
  第5セクションで「病気ではない／誰にでも起こる」と明言してから解決策に進む。
- カラコンは**若年層向けの「盛る」文脈を使わない**。「ととのえる」「なじむ」「印象」で統一。
- 医療機器としての注意文と「個人差があります」を各セクションに配置。

## 3. クリエイティブ（画像素材）

すべてSVGで新規制作しています。写真素材へ差し替える場合も、レイアウトはそのまま使えます。

## 4. 実装メモ

- ライブラリ不使用のバニラJS。CMSへ貼り付ける際もJSの競合が起きにくい構成です。
- アクセシビリティ：タブは `role="tablist"` ＋左右キー操作、FAQは `aria-expanded`、
  画像には内容を説明する `alt` を付与。`prefers-reduced-motion` にも対応。
- レスポンシブ：900px以下でヘッダーナビを省略、640px以下で画面下に追従CTAを表示。

## 5. 今後の拡張案（第2フェーズ）

1. **セルフチェック診断**：3問程度の質問に答えると「おすすめタイプ」が出るミニ診断。CVの手前に配置。
2. **店舗別の在庫・体験可否**：店舗詳細ページと連携し「遠近両用の試着ができる店舗」を絞り込み。
3. **カラコン色見え比較**：瞳の色（明るめ／暗め）を選ぶと発色イメージが切り替わるシミュレーター。
4. **家族向け訴求バナー**：「親御さんへのプレゼントに」という切り口で母の日・父の日と連動。
5. **記事コンテンツ**：「老眼鏡と遠近両用コンタクトの併用術」などSEO記事を追加し、本ページへ内部リンク。
