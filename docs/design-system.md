# デザインシステム：DESIGN_6「graphite ink on warm paper」

このページは、いただいたスタイルリファレンス **DESIGN_6** に沿って全面的に作り直しています。
以前のピンク基調（`#e4638a`）のトンマナは廃止し、**完全な無彩色（アクロマティック）** に統一しました。

すべての値は `assets/css/style.css` の `:root` にトークンとして集約しています。
このファイルはその「なぜそうなっているか」の説明書です。

---

## 1. 5つの原則

| # | 原則 | このページでの実装 |
| --- | --- | --- |
| 1 | **色相を使わない** | ブランドピンク・ステータスの緑や赤を含め、色は一切ありません。強弱は「文字の太さ」「面（白／ミスト）」「余白」で表します |
| 2 | **影を使わない** | `box-shadow` はページ内に1つもありません。カードやパネルの立体は **1px のヘアライン（`#0000001a`）** だけで表します |
| 3 | **Webフォントを読まない** | Google Fonts（Noto Sans JP）の読み込みを削除。OS標準の書体で表示します（表示が速く、OSのアクセシビリティ設定にも追従します） |
| 4 | **文字は 14 / 16 / 24px の3段階だけ** | 24pxを超える文字はページ内に存在しません。見出しも電話番号も24pxが上限です |
| 5 | **ホバーは点滅ではなく呼吸** | すべてのホバーは 5%の黒（`#0000000d`）を敷くだけ。動く・光る演出はしません |

---

## 2. カラートークン

| トークン | 値 | 用途 |
| --- | --- | --- |
| `--color-pure-white` | `#ffffff` | 主となる読みの面。本文セクション・カード |
| `--color-sidebar-mist` | `#f9f9f9` | 副次的な面。ファーストビュー・カードを並べるセクション・CV・フッター |
| `--color-graphite-ink` | `#0d0d0d` | 本文・見出し・アイコン。**純黒は使いません**（コントラスト18.5:1） |
| `--color-mid-ash` | `#5d5d5d` | 補助テキスト（リード文・カード本文） |
| `--color-hollow` | `#8f8f8f` | 注釈・ラベル・非活性 |
| `--color-hairline` | `#0000001a` | 1pxの罫線。**唯一の構造的な区切り** |
| `--color-hover-veil` | `#0000000d` | ホバー時の面／文中マーカー |
| `--color-ink-press` | `#000000` | 反転面のみ（KVの「遠近両用レンズ」タグなど） |
| `--color-deep-charcoal` | `#00000080` | KV写真の下に敷くスクリム |
| `--color-edge-gray` | `#e6e6e6` | 少し強い区切り／トグルのOFF状態 |

## 3. タイポグラフィ

```
caption  14px / line-height 1.43   … 注釈・ラベル・ボタン・カード本文
body     16px / line-height 1.5    … 本文・小見出し
heading  24px / line-height 1.33   … セクション見出し・H1・電話番号（上限）
```

- ウェイトは **400 / 500 / 600** の3つだけ。700（太字）は使いません。
- 和文の長文だけ `--leading-prose: 1.8` を当てています。
  DESIGN_6 の 1.5 は欧文前提で、日本語だと行が詰まって読みづらいための調整です。
  詰めたい場合は `:root` のこの1行を `1.5` に戻してください。
- 法定表記など、どうしても小さくしたい箇所のみ `--text-micro: 12px` を使用（DESIGN_6の拡張）。

### 階層のつけ方

サイズが3段階しかないため、階層は **ウェイトの差** でつくります。
ファーストビューが典型例です。

```
遠近両用コンタクトレンズ   24px / 600  ← 商品名（特集）
見えるって、こんなに…     24px / 400  ← キャッチコピー
```

同じ大きさでも、太さの差だけで「主」と「従」が読み取れます。

## 4. 角丸（ラジウス）

| 要素 | 値 |
| --- | --- |
| カード・図版・ナビ項目・入力面 | **10px** |
| ボタン（CTA・ゴースト・電話） | **ピル（9999px）** |
| バッジ・チップ・タグ | **0px（角丸なし）** |

バッジだけ0pxで角を立てるのは DESIGN_6 の意図的な破調です。
カードの10pxとバッジの0pxが同居することで、面と情報ラベルが視覚的に分離します。

**同じコントロール群の中でラジウスを混ぜないでください。**
CTAとゴーストボタンは必ず同じピルで揃えています。

---

## 5. 面（サーフェス）の使い分け

DESIGN_6 は「明暗の帯を交互に敷かない」設計です。ページ全体が1枚の明るい面で、
区切りはヘアラインが担います。このページでは次の2枚だけを使っています。

| 面 | 使う場所 |
| --- | --- |
| Pure White `#ffffff` | セルフチェック／レンズの仕組み／カラコン／体験者の声／動画 |
| Sidebar Mist `#f9f9f9` | ファーストビュー／生活シーン／全店眼科併設／CV／フッター |

ミストを当てているのは **白いカードを並べるセクション** です。
白の上に白いカードだとヘアラインだけが頼りになるため、面を一段落として浮かせています。

---

## 6. 図版（SVG）の扱い

`tools/retheme-svg.py` で、すべての図版を無彩色へ変換しています。

- 変換方法は **知覚輝度（Rec.709）をそのままグレーに置き換える** 方式です。
  図の明暗構造は元のまま保たれ、色相だけが消えます。
- `feDropShadow` の適用を外しています（原則2「影を使わない」）。
- 図版内のフォント指定も、Webフォントを読まないシステムフォントスタックへ変更しています。

### 色を残しているもの（意図的）

| 対象 | 理由 |
| --- | --- |
| `color-lens.svg` の4色のレンズ | **色そのものが商品情報** です。ブラウン／オリーブ／グレージュ／ブラックを無彩色にすると意味が失われます。DESIGN_6 の「色＝データであり、装飾ではない」に沿った判断です |
| `kv-photo.jpg`（メインビジュアル） | 人物写真はUIのchromeではなくコンテンツです。ページ内で唯一の色があることで、写真そのものに視線が集まります |

写真もモノクロにしたい場合は、`assets/css/style.css` の `.p-kv__base` に
`filter: grayscale(1);` を1行足してください。

## 7. 既知のトレードオフ（ご確認ください）

DESIGN_6 を忠実に適用した結果、**広告の受け皿（LP）としては弱くなる点** が2つあります。
どちらも仕様どおりですが、運用判断で変えられるように書いてあります。

### 7-1. CTAに専用色がない

DESIGN_6 は「primary action: no distinct CTA color」と明記しており、
主ボタンは *白地＋1pxヘアライン＋ピル* です（リファレンスのログインボタンと同じ）。
そのため、ページ内でCTAが視覚的に突出しません。

**目立たせたい場合**は、`assets/css/style.css` の末尾に次を追記してください。
無彩色のまま、反転面（ink press）でCTAだけを立たせます。

```css
/* CTAを反転面で強調する（DESIGN_6からの意図的な逸脱） */
.c-btn--cv {
  background: var(--color-graphite-ink);
  border-color: var(--color-graphite-ink);
  color: var(--color-pure-white);
}
.c-btn--cv:hover {
  background: var(--color-ink-press);
  border-color: var(--color-ink-press);
}
```

### 7-2. 見出しの最大サイズが24px

DESIGN_6 は「24pxを超える文字を使わない」と定めています。
ご指示のあった「ファーストビューに『遠近両用コンタクトレンズ特集』を大きく掲出」は、
**24px／ウェイト600＋反転バッジ**という、この体系の中での最大表現で実装しています。
以前のピンク版（最大36px）と比べると、物理的な文字は小さくなります。

より大きく出す必要がある場合は `:root` の `--text-heading` を引き上げてください
（例：`32px`）。1箇所の変更で見出し・H1・電話番号にまとめて反映されます。

## 8. 変更のしかた

| やりたいこと | 触る場所 |
| --- | --- |
| 全体のトーンを変える | `assets/css/style.css` の `:root` |
| 見出しを大きくする | `--text-heading` |
| 和文の行間を調整する | `--leading-prose` |
| 図版の色を作り直す | `tools/retheme-svg.py` を編集して再実行 |
| 確認用の1ファイル版を更新する | `python3 tools/build-preview.py` |

CSSやSVGを更新したら、**必ず `python3 tools/build-preview.py` を実行して
`preview.html` を作り直してください**（クライアント確認用の1ファイル版です）。
