## 表示確認（3つの方法）

### 1. `preview.html` をダブルクリック（いちばん簡単）

CSS・JS・画像をすべて埋め込んだ1ファイル版です。
ダウンロードしてダブルクリックすれば、サーバーもネット接続もなしでそのまま開けます。
※ 内容を更新したら `python3 tools/build-preview.py` で作り直してください。

### 2. GitHub Pages で URL を発行する（推奨）

公開URL（発行後はここで見られます）:
**<https://rockdanceai2025-sys.github.io/city-contact-enkin/>**

設定はGitHubの画面から1回だけ行います。

1. GitHubのリポジトリを開く → 上部の **Settings**（設定）
2. 左メニューの **Pages**
3. Source（ソース）で **Deploy from a branch** を選択
4. Branch（ブランチ）で **`claude/shunnsai-megumi-lp-thread-edit-vegobz`** を選ぶ
5. その右のフォルダは **`/ (root)`** のまま → **Save**
6. 1〜2分待つと、上記のURLで閲覧できます（スマホからもOK・URLで共有できます）

> **ブランチはどれを選べばいい？**
> チャット（スレッド）での修正はすべて
> **`claude/shunnsai-megumi-lp-thread-edit-vegobz`** に反映されます。
> ここを選んでおくと、修正のたびに1〜2分で公開URLの中身が自動で新しくなります。
> 別のブランチを選んでいる場合、チャットでの修正は公開URLに反映されません。

うまく表示されないときは、ブラウザで **Ctrl + F5**（Macは Cmd + Shift + R）を押して
キャッシュを消してから読み込み直してください。

**検索エンジン対策について**
このページには `<meta name="robots" content="noindex, nofollow">` を入れてあるため、
GitHub Pagesで公開してもGoogleなどの検索結果には表示されません。
ただしURLを知っている人は誰でも閲覧できる状態になります（非公開にするにはGitHub Enterpriseが必要）。
社外に出したくない場合は、`preview.html` をメール等で直接お渡しする方法をおすすめします。

### 3. ローカルでサーバーを立てる（開発者向け）

```bash
python3 -m http.server 8000
# → http://localhost:8000/ をブラウザで開く
```

2. Claude が `index.html` などを書き換えて、

**伝え方の例**

- 「ファーストビューのキャッチコピーを『〇〇』に変えて」
- 「料金表に『△△プラン 5,500円』の行を追加して」

> `preview.html`（1ファイル版）も修正のたびに作り直して保存します。

## コーポレートサイトへの組み込み手順

1. `index.html` の `<header>` / `<footer>` / パンくずを、**本番CMSの共通パーツに差し替え**てください
   （本ファイルのヘッダー・フッターは、トンマナ確認用の簡易版です）。
2. `assets/` を `/enkin/assets/` として配置するか、既存のアセットディレクトリへ統合してください。
3. サイト内リンクは `https://www.city-contact.com/...` の絶対パスで記述しています。
   CMS側の運用に合わせてルート相対（`/item/` など）へ変更しても動作します。
4. OGP画像はSVGで用意しています。SNSシェアの互換性を考える場合は
   `assets/img/ogp.svg` を **1200×630のPNGに書き出して** `og:image` を差し替えてください。

## 配色（トンマナ）

`assets/css/style.css` の `:root` にすべて集約しています。
コーポレートサイトの正式なブランドカラーが確定している場合、この数値の差し替えだけで全体に反映されます。

| 変数 | 値 | 用途 |
| --- | --- | --- |
| `--c-primary` | `#e4638a` | メインピンク（CTA・アイコン） |
| `--c-primary-dark` | `#c2456c` | 見出し・ホバー |
| `--c-secondary` | `#f292af` | サブピンク（枠線・タグ） |
| `--c-primary-light` | `#fdeff3` | 淡いピンク背景 |
| `--c-cream` | `#faf5ec` | ベージュ背景（フッター等） |

フォントは `Noto Sans JP`（Google Fonts）を使用しています。
コーポレートサイト側で別のWebフォントを読み込んでいる場合は、`--font` を合わせてください。

## 掲載前チェック（重要）

### ⚠️ 本番公開時に必ず削除するもの

`index.html` の冒頭に、確認用サイトを検索結果に出さないための指定が入っています。

```html
<meta name="robots" content="noindex, nofollow">
```

**本番（www.city-contact.com）へ設置する際は、この1行を必ず削除してください。**
残したまま公開すると、本番ページが検索結果に表示されなくなります。
（ルート直下の `robots.txt` も確認用のものなので、本番では不要です）
