コーポレートサイト <https://www.city-contact.com/> に追加する
**遠近両用コンタクトレンズ特集ページ（遠近両用カラコン含む）** の制作物一式です。

- コンセプト：**「誰にも気づかれずに、世界が変わる。」**
- 想定URL：`https://www.city-contact.com/enkin/`
- 構成：1ページ完結のコンテンツページ（縦スクロール型）

## 表示確認

ビルド不要の静的HTMLです。ローカルで確認する場合：

```bash
python3 -m http.server 8000
# → http://localhost:8000/ をブラウザで開く
```

## コーポレートサイトへの組み込み手順

1. `index.html` の `<header>` / `<footer>` / パンくずを、**本番CMSの共通パーツに差し替え**てください
   （本ファイルのヘッダー・フッターは、トンマナ確認用の簡易版です）。
2. `assets/` を `/enkin/assets/` として配置するか、既存のアセットディレクトリへ統合してください。
3. サイト内リンクは `https://www.city-contact.com/...` の絶対パスで記述しています。
   CMS側の運用に合わせてルート相対（`/item/` など）へ変更しても動作します。
4. OGP画像はSVGで用意しています。SNSシェアの互換性を考える場合は
   `assets/img/ogp.svg` を **1200×630のPNGに書き出して** `og:image` を差し替えてください。

## 配色（トンマナ）

`assets/css/style.css` の `:root` にすべて集約しています。
コーポレートサイトの正式なブランドカラーが確定している場合、この数値の差し替えだけで全体に反映されます。

| 変数 | 値 | 用途 |
| --- | --- | --- |
| `--c-primary` | `#0e6fb8` | メインブルー（清潔感・信頼） |
| `--c-primary-dark` | `#0a3a5c` | 見出し・フッター |
| `--c-accent` | `#16b8c8` | アクセント（レンズの透明感） |
| `--c-warm` | `#c97a4b` | カラコンセクションの暖色 |
| `--c-cv` | `#ff7a3d` | CTAボタン |

フォントは `Noto Sans JP`（Google Fonts）を使用しています。
コーポレートサイト側で別のWebフォントを読み込んでいる場合は、`--font` を合わせてください。

## 掲載前チェック（重要）

コンタクトレンズは高度管理医療機器のため、原稿には以下を必ず残してください。

- 「必ず眼科医の検査・処方を受けてお求めください」の注意文（CVセクション内に記載済み）
- 効果効能の断定表現を避ける（本ページは「個人差があります」を各所に明記済み）
- お客様の声は**イメージ原稿**です。実際の声に差し替えるか、掲載可否をご判断ください
- 電話番号・受付時間・展開エリアは公開情報をもとに記載しています。最新情報にご確認のうえ差し替えてください
