# 遠近両用コンタクトページ（シティコンタクト コーポレートサイト 追加コンテンツ）

コーポレートサイト <https://www.city-contact.com/> に追加する
**遠近両用レンズのコンテンツページ（熟年世代向け遠近両用カラコン含む）** の制作物一式です。

- ページタイトル：**遠近両用コンタクトレンズ特集｜全店眼科併設で安心の処方**
- 位置づけ：コーポレートサイト内の特集ページ。**WEB広告からの受け皿（ランディング先）**
- クリエイティブコンセプト：**「誰にも気づかれずに、世界が変わる。」**
- デザインシステム：**DESIGN_6「graphite ink on warm paper」**（完全無彩色・影なし・システムフォント）
- 資料：サイト構成案 ページ2 ／ 20260707 定例会企画書に準拠
- 想定URL：`https://www.city-contact.com/enkin/`
- 構成：1ページ完結のコンテンツページ（縦スクロール型）

## 表示確認（3つの方法）

### 1. `preview.html` をダブルクリック（いちばん簡単）

CSS・JS・画像をすべて埋め込んだ1ファイル版です。
ダウンロードしてダブルクリックすれば、サーバーもネット接続もなしでそのまま開けます。
※ 内容を更新したら `python3 tools/build-preview.py` で作り直してください。

### 2. GitHub Pages で URL を発行する

1. GitHubのリポジトリを開く → 上部の **Settings**
2. 左メニューの **Pages**
3. Source で **Deploy from a branch** を選択
4. Branch に **`claude/dev-start-wffcis`** ／ フォルダは **`/ (root)`** を選んで **Save**
5. 1〜2分後、`https://rockdanceai2025-sys.github.io/city-contact-enkin/` で閲覧できます

（スマホからも確認でき、URLで共有もできます）

**検索エンジン対策について**
このページには `<meta name="robots" content="noindex, nofollow">` を入れてあるため、
GitHub Pagesで公開してもGoogleなどの検索結果には表示されません。
ただしURLを知っている人は誰でも閲覧できる状態になります（非公開にするにはGitHub Enterpriseが必要）。
社外に出したくない場合は、`preview.html` をメール等で直接お渡しする方法をおすすめします。

### 3. ローカルでサーバーを立てる（開発者向け）

```bash
python3 -m http.server 8000
# → http://localhost:8000/ をブラウザで開く
```

## コーポレートサイトへの組み込み手順

1. `index.html` の `<header>` / `<footer>` / パンくずを、**本番CMSの共通パーツに差し替え**てください
   （本ファイルのヘッダー・フッターは、トンマナ確認用の簡易版です）。
2. `assets/` を `/enkin/assets/` として配置するか、既存のアセットディレクトリへ統合してください。
3. サイト内リンクは `https://www.city-contact.com/...` の絶対パスで記述しています。
   CMS側の運用に合わせてルート相対（`/item/` など）へ変更しても動作します。
4. OGP画像はSVGで用意しています。SNSシェアの互換性を考える場合は
   `assets/img/ogp.svg` を **1200×630のPNGに書き出して** `og:image` を差し替えてください。

## 配色（トンマナ）

**DESIGN_6「graphite ink on warm paper」** に準拠した、**完全な無彩色**です。
ブランドピンクを含め、ページ内に色相は一切ありません。
強弱は「文字の太さ」「面の明るさ」「余白」で表しています。

`assets/css/style.css` の `:root` にすべて集約しています。

| 変数 | 値 | 用途 |
| --- | --- | --- |
| `--color-pure-white` | `#ffffff` | 主となる読みの面・カード |
| `--color-sidebar-mist` | `#f9f9f9` | ファーストビュー・カード列・CV・フッター |
| `--color-graphite-ink` | `#0d0d0d` | 本文・見出し・アイコン |
| `--color-mid-ash` | `#5d5d5d` | 補助テキスト |
| `--color-hollow` | `#8f8f8f` | 注釈・ラベル |
| `--color-hairline` | `#0000001a` | 1pxの罫線（唯一の構造的な区切り） |
| `--color-hover-veil` | `#0000000d` | ホバー時の面・文中マーカー |

**この体系の3つの約束**

1. **影は使いません。** 立体は 1px のヘアラインだけで表します（`box-shadow` は0件）。
2. **Webフォントは読み込みません。** OS標準の書体で表示します（Noto Sans JP の読み込みは削除済み）。
3. **文字は 14 / 16 / 24px の3段階だけ。** 24pxを超える文字はページ内にありません。

設計意図・変更方法・意図的なトレードオフは **[docs/design-system.md](docs/design-system.md)** に
まとめています。**トンマナの調整をされる前に、こちらを先にご覧ください。**

### ご確認いただきたい2点（仕様どおりですが、運用判断が要ります）

- **CTAに専用色がありません。** DESIGN_6 は「CTAに固有の色を持たせない」と定めているため、
  予約ボタンは白地＋1pxの枠線です。広告の受け皿として目立たせたい場合の
  切り替え方（CSS 6行）を design-system.md の 7-1 に記載しています。
- **見出しの最大が24pxです。** ファーストビューの「遠近両用コンタクトレンズ特集」は
  この体系での最大表現（24px／ウェイト600＋反転バッジ）で掲出しています。
  もっと大きくしたい場合は `--text-heading` の1行変更で対応できます（7-2）。

### 図版（SVG）について

図版は `tools/retheme-svg.py` で無彩色へ変換しています（知覚輝度をそのままグレーへ置換）。
ただし **遠近両用カラコンの4色（ブラウン／オリーブ／グレージュ／ブラック）は色を残しています**。
色そのものが商品情報だからです。メインビジュアルの写真も、コンテンツとしてそのままの色です。

## 掲載前チェック（重要）

### ⚠️ 本番公開時に必ず削除するもの

`index.html` の冒頭に、確認用サイトを検索結果に出さないための指定が入っています。

```html
<meta name="robots" content="noindex, nofollow">
```

**本番（www.city-contact.com）へ設置する際は、この1行を必ず削除してください。**
残したまま公開すると、本番ページが検索結果に表示されなくなります。
（ルート直下の `robots.txt` も確認用のものなので、本番では不要です）

### 原稿まわり

コンタクトレンズは高度管理医療機器のため、原稿には以下を必ず残してください。

- 「必ず眼科医の検査・処方を受けてお求めください」の注意文（CVセクション内に記載済み）

- **「全店 眼科併設」**の表現でページ全体を統一しています（2026/08 ご指示にもとづく）。診療日・診療時間のみ「店舗により異なります」と注記
- **製品名**（アイコフレ マルチステージ／スマートフォーカスリング ブラウン）は企画書の記載にもとづく一例です。取扱状況をご確認ください
- **メインビジュアルの写真**は提案書内の画像を切り出したもので、解像度が256×326pxしかありません。**元データのご支給をお願いします**
- **YouTube動画**は準備中のプレースホルダです。公開後、`index.html` 内のコメント部分のiframeに差し替えてください
- 電話番号・受付時間・展開エリアは公開情報をもとに記載しています。最新情報にご確認のうえ差し替えてください
